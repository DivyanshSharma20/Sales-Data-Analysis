Sales Data Analysis Project

Project Overview
This project focuses on analyzing retail sales data to discover meaningful business insights and trends.
Using Python for data analysis and Power BI for visualization, the project helps identify sales performance, profitable categories, customer behavior, and regional trends.

Objectives
Analyze sales and profit trends
Identify top-performing regions and customers
Discover profitable and loss-making categories
Perform Exploratory Data Analysis (EDA)
Build an interactive Power BI dashboard

Tools & Technologies Used
Python
Pandas
NumPy
Matplotlib
Power BI
ydata-profiling
Git & GitHub

Project Workflow
1. Data Collection
Imported retail sales dataset (Superstore dataset)
2. Data Cleaning
Handled missing values

Fixed data formatting issues
